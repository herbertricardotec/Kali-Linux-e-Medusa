# Kali-Linux-e-Medusa
Projeto educacional de auditoria ofensiva. Lab isolado com Kali Linux e Medusa para simular força bruta em FTP, DVWA e SMB (Metasploitable 2). Documentação de testes, wordlists, resultados e mitigações. Ambiente controlado no VirtualBox (rede host-only). Foco em aprendizado ético e boas práticas de defesa.
